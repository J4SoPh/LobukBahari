# BahariAI — Smart Tourism Wisata Bahari

Prototype aplikasi penelitian:
**Digitalisasi Promosi Wisata Bahari melalui Layanan Smart Tourism Berbasis Artificial Intelligence**

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` menggunakan browser.
3. Tidak membutuhkan server untuk prototype awal.

## Modul prototype
- Katalog destinasi (ada)
- Pencarian destinasi (ada)
- AI Recommendation sederhana berbasis scoring preferensi (ada)
- AI Tourism Assistant berbasis knowledge base (ada dan harus dikembangkan)
- Itinerary generator sederhana (ada dan harus dikembangkan)
- Dashboard pengelola
- Insight sentimen (mockup)

## Pengembangan untuk penelitian
Tahap berikutnya dapat mengganti AI prototype dengan:
- Backend FastAPI/Node.js
- PostgreSQL
- Sentence-BERT/IndoBERT
- Hybrid Recommendation
- RAG + LLM
- Sentiment Analysis Bahasa Indonesia
- Login Admin/Pokdarwis
- Dashboard analitik
- Dataset destinasi wisata bahari Madura

## Struktur
index.html  - antarmuka
style.css   - desain
app.js      - data dan logika prototype
